### 关键技术结论（重要，避免重复踩坑）
1. NMF 要求目标非负，而 ESM 权重有正负 → 必须先整体平移 `offset = min(W)`，
   且 `‖W-offset‖/‖W‖ ≈ 3~5.5`，导致“相对非负目标的误差”换算到原权重会被放大同样倍数。
   评估时必须同时报两个数，以“相对原权重”为准。
2. `--shift min`（整体标量平移）实测**优于** `--shift row`（逐行平移），尽管后者目标范数更小，
   与直觉相反。默认已设为 `min`。
3. `rank = min(in,out)`（满阶）时存在精确解 `A=W-offset, S=I, B=I`，但现有迭代求解器
   达不到（pgd 2000 步 relW≈0.15）；真正有意义的区间是 `rank < min(in,out)`。
4. **训练时 Adam 的学习率与参数尺度无关**，lr=1e-2 时一步就能把分解破坏掉
   （相对重构误差 0.55 → 4.89）。因此 `train_nmf.py` 实现了信任域保护：
   每步检查 re​construction 误差，超过 `初始值×(1+--max-recon-degradation)` 就回滚并
   把 lr 减半重试。实测 `--lr 3e-3` 会自动降到 7.5e-4。
5. 实验结论：单层 `layers.5.fc1`、rank=160（0.688× 参数）时，权重层面 relW=0.55 但模型层面
   未遮挡 top-1 一致率 0.93~0.99；32 个批次的蒸馏训练让**同分布** KL 0.119→0.057、
   masked 困惑度 11.42→10.25（原模型 10.27），但**跨分布**无改善。

### ★ 重大 bug 与修复：三因子微调的学习率必须按"扰动增益"分组标定
- 现象：全模型训练时，即使 lr 已降到 1e-6，模型仍被训坏（masked ppl 14→86）
- 根因：中间矩阵 S 夹在 A、B 之间，逐元素同号扰动被放大 `(A 行和)×(B 列和)` 倍；
  NMF 解的尺度存在歧义（实测 layers.5.fc1 的 A max=0.30 而 B max=17878）。
  实测 δ=1e-4 同号扰动：k_proj 相对误差 A:0.016→0.84、S:0.016→10.87、B:0.016→0.022。
  Adam 步长 ≈ lr·sign(g)，与梯度幅值无关 → 单步 lr=1e-4 就把全模型重构误差从 0.0417 爆到 1.699。
- 修复：`train_nmf.factor_perturbation_gains` + `build_parameter_groups`，
  `lr_factor = --lr / gain_factor`（`--lr-scale auto` 默认）。
  实测分组 lr：A 5.6e-8 / S 3.6e-9 / B 2.5e-5 / offset 2.8e-5，训练全程稳定。
- 附带：`--save-every` 周期性保存检查点；`--kl-scope {masked,all}`；token 预算分批；
  每 epoch 重新打乱。
